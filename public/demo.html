Despliega tu propio ApliArte Directo

Esta demo pública es 100% aislada en navegador. Para tener tu propio estudio privado de streaming con WebRTC y OBS, utiliza estas opciones:

Copia este prompt y pégalo en Kodee (el agente de IA en tu panel VPS de Hostinger):

Despliega de forma soberana y segura el proyecto apliarte-directo en este servidor: 1. Clona el repositorio oficial: git clone https://github.com/erbolamm/apliarte-directo.git && cd apliarte-directo 2. Prepara la configuración de entorno: cp .env.example .env - Genera una contraseña segura y aleatoria para PANEL_PASS. - Pídeme mi Stream Key de Twitch y configúrala en TWITCH_STREAM_KEY. - Configura una sala y clave propia para VDO_ROOM y VDO_PASS. 3. Inicia el stack de contenedores Docker: docker compose up -d 4. REGLA DE SEGURIDAD CRÍTICA: - Mantén los puertos del panel web restringidos a la red privada (Tailscale o IP local). - No expongas /admin ni los puertos de control a internet público. - Muestra las URLs de acceso privado al terminar.
