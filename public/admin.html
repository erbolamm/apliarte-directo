📋 Guía Rápida para OBS Studio:

  1. En OBS Studio, pulsa + en Fuentes y elige Navegador.
  2. Pega la URL copiada en el campo URL.
  3. Define Ancho: 1920 y Alto: 1080.
  4. Marca «Actualizar el navegador cuando la escena se active» y pulsa Aceptar.

Configura tus parámetros de conexión de forma visual. Se almacenan de forma segura en el servidor con permisos restringidos (0600).
