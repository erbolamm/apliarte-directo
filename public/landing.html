Instálalo en 3 pasos

Descarga, descomprime y haz doble clic. No necesitas Git ni Docker para empezar.

⬇ Descargar ZIP 🚀 Primeros Pasos 📖 Guía de Comandos ▶ Abrir mi Directo instalado 🔴 Probar la demo

«Abrir mi Directo» funciona solo si ya lo has arrancado en este equipo. Esta página no arranca la aplicación por sí sola.

1

Instala Node.js LTS una vez

Descárgalo de nodejs.org. Si falta, el icono de inicio abre esa página automáticamente.

https://nodejs.org
2

Descarga y descomprime

Pulsa «Descargar ZIP» arriba y descomprime la carpeta. En su interior encontrarás la guía EMPEZAR.html para seguirlo todo con un doble clic. No necesitas Git.

Si prefieres Git, usa esta opción secundaria:

git clone https://github.com/erbolamm/apliarte-directo.git
3

Haz doble clic

En la carpeta descomprimida, abre Iniciar directo.command (Mac) o Iniciar directo.bat (Windows). Si macOS bloquea el icono la primera vez: clic derecho → Abrir.

Desde una terminal, en esa carpeta:

npm run directo

Qué verás la primera vez

Preparación automática

El primer arranque instala lo que necesita y luego abre el navegador en una página de un solo uso para crear la contraseña del panel. La contraseña se muestra una sola vez: guárdala. El enlace privado no se muestra en la ventana del lanzador ni se imprime en pantalla.

Mantén la ventana abierta

El lanzador te muestra las direcciones que usarás en OBS. Mientras emites, no cierres la ventana: si cierras esta ventana, se detiene todo.

Conéctalo a OBS

Añade dos «Fuentes de navegador» de 1920 × 1080. Copia cada dirección en su propia fuente:

Capa transparente (avatares y rótulos)

http://127.0.0.1:7979/plano?transparente=1

Fondo animado

http://127.0.0.1:7979/fondo.html

Panel privado (en tu ordenador)

http://127.0.0.1:7979/admin

Twitch y YouTube a la vez

En OBS → Ajustes → Emisión, elige Servicio personalizado. En «Servidor» pega:

rtmp://127.0.0.1:1935/live

En «Clave de retransmisión», escribe cualquier palabra, por ejemplo «directo». Pega tus claves reales de Twitch y YouTube en el panel: «⚙️ Config & OBS» → «🔑 Credenciales & Red»; no las pongas en OBS.

Para emitir a ambas plataformas necesitas ffmpeg. Sin ffmpeg, la capa y el panel siguen funcionando. https://ffmpeg.org/download.html

Si ya usas un gestor de paquetes: Mac brew install ffmpeg Windows winget install ffmpeg

Problemas frecuentes

Puerto ya en uso

Puede haber otra ventana del lanzador abierta. Ciérrala y vuelve a intentarlo.

No se encuentra ffmpeg

Instálalo desde el enlace anterior y reinicia el lanzador. Sin él, la capa y el panel funcionan, pero no la emisión simultánea.

macOS bloquea el icono

En el primer arranque, haz clic derecho sobre Iniciar directo.command → Abrir.

¿Olvidaste la contraseña del panel?

Cierra la ventana de ApliArte Directo. En la carpeta del proyecto, entra en data y borra el archivo data/panel-auth.json. Vuelve a hacer doble clic en Iniciar directo: se abrirá el navegador para crear una contraseña nueva, igual que la primera vez. Tus avatares, voces y demás ajustes no se pierden.

Avanzado: en tu VPS

Para emitir 24/7 sin depender de tu ordenador personal, puedes alojar ApliArte Directo en un servidor en la nube. La opción recomendada y probada es un VPS KVM en Hostinger con el enlace de ApliArte (enlace de afiliado, 1 vCPU y 2 GB RAM son suficientes para la suite).

El instalador automatizado para VPS KVM Ubuntu/Debian se ejecuta mediante el script de despliegue usando el commit aprobado RELEASE_COMMIT_SHA. En el terminal SSH del VPS, el comando documentado es:

curl -fsSL https://raw.githubusercontent.com/erbolamm/apliarte-directo/RELEASE_COMMIT_SHA/deploy/provision.sh | sudo bash -s -- --ref RELEASE_COMMIT_SHA

Sustituye ambas apariciones del marcador por el mismo hash aprobado de 40 caracteres. Sin dominio, el acceso es privado por túnel SSH; con --domain se expondría también el panel, por lo que requiere revisión de seguridad. Lee la guía VPS completa antes de hacer nada.

Arquitectura avanzada

Servicios aislados en una red privada. No necesitas entender esta sección para empezar.

# Servicios y comunicaciones [ Twitch / Internet ] <──(WHIP WebRTC)── [ whip (Chromium Headless) ] ▲ │ (Internal HTTP Control :3000) [ Mobile Cockpit / OBS ] ───(HTTP / WS)─────► [ overlay (Node.js 22 LTS :7979) ] ▲ │ (Reverse Proxy Pass) [ Caddy SSL (Optional) ] ◄──(Let's Encrypt)─────┘
Instalación manual con Docker (opcional)

Esta opción es para quien ya conoce Docker. Un sitio web no puede arrancar Docker ni detectar un clon local por sí solo.

Abre el panel de una instalación local ya iniciada:

http://localhost:7979/admin

Si ya tienes configurado Docker Compose en tu carpeta, puedes usar:

docker compose up -d

Para actualizar un clon después de respaldar tus cambios, revisa la versión y usa:

git pull --ff-only

Crear tu fork en GitHub ↗
