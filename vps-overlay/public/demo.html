Despliega tu propio ApliArte Directo

Esta demo pública es 100% aislada en navegador. Para tener tu propio estudio privado de streaming con WebRTC y OBS, utiliza estas opciones:

Copia este prompt y pégalo en Kodee (el agente de IA en tu panel VPS de Hostinger):

Despliega de forma limpia y segura el proyecto ApliArte Directo con Docker Compose en este servidor: 1. Instala Docker y el plugin Docker Compose si aún no están instalados. 2. Clona el repositorio oficial si no existe: git clone https://github.com/erbolamm/apliarte-directo.git && cd apliarte-directo 3. Si no existe el archivo .env, copia la plantilla de ejemplo: cp -n .env.example .env (No me pidas contraseñas ni claves de emisión en este chat; las configuraré después de forma segura desde la interfaz web). 4. Levanta el stack en segundo plano: docker compose up -d 5. Comprueba el estado con 'docker compose ps' y facilítame la URL de acceso web privado (puerto 7979 por IP local o Tailscale) y el enlace de primer acceso para configurar mis claves en el navegador sin exponer el panel a internet público.

¿Necesitas un VPS? Hostinger con el enlace de ApliArte (enlace de afiliado).

git clone https://github.com/erbolamm/apliarte-directo.git cd apliarte-directo cp .env.example .env docker compose up -d
