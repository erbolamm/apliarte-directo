Private Pizarra Plus

A private add-on, not a replacement for Admin and not approved for publication. The original Admin, pizarra and crystal routes remain unchanged. This document records the operating and regression contract of the new interface.

Use · Drawing · OBS · Admin · Boundaries · Acceptance

Private access

  1. Enable only with Javier's approval: DIRECTO_PIZARRA_PLUS=1 on the 7979 panel process. It is disabled by default.
  2. Open /pizarra-plus through the existing private HTTPS Tailscale Serve origin. Do not configure Funnel or a public proxy for these routes.
  3. For OBS drawing output, a separate transparent browser source uses /cristal-plus on the same private panel origin. Do not replace existing sources without approval.

Drawing and Apple Pencil

Only one pointer owns each stroke. Touch is ignored by default; mouse and Pencil work. Enable “Dibujar con dedo” only when finger drawing is intended; do not enable it for palm rejection. A different pointer cannot move or end the active stroke. Cancellation does not commit a geometric shape.

Tools, colors, undo, redo and clear retain the existing drawing behavior. Coordinates are normalized to the 16:9 drawing canvas. Drawing is blocked while the private socket is disconnected. Up to 4,000 segments are retained in server memory only; reconnect replays them, but restarting the panel clears drawings. No durable drawing-history feature is claimed.

OBS controls and screenshots

The OBS menu discovers actual scenes and inputs using the existing local OBS WebSocket client. Choose the audio input explicitly; a source without mute support disables that control. Scene and mute changes wait for OBS confirmation. There are no start/stop streaming actions.

“Mostrar captura OBS” fetches still JPEG screenshots of the current program scene. Default interval: 5 seconds; options: 1, 2, 5 or 10 seconds. Requests do not overlap; hidden pages stop polling. This is not a video stream. Errors are visible rather than silently indicating success.

The existing Admin is reused

Dropdowns are anchored below a positioned, non-clipping header; closed menus are explicitly hidden. Gesture suppression is limited to the drawing canvases, so menu content can scroll on touch devices without changing Pencil stroke ownership.

The Admin menu lazily embeds /admin in a same-origin iframe. Its tab selector is populated from the real Admin navigation buttons, not a second hardcoded catalog. Camera, audio, chats, saved commands, users, channels and messages remain owned by their existing implementation. Opening Admin separately remains supported.

A1 lists and commands keep using /api/panel/lista and /api/panel/comandos-bot, persisted in ignored data/panel/. The plus creates no duplicate store. Botrix settings remain browser-local in the existing Admin; A3 server persistence is not part of this change.

Security and ownership

  • Assets live in private/, outside public/, with exact route allowlists and no-store responses.
  • Page, guide, OBS API and drawing socket require private local/Tailscale access. Public-domain Host and foreign Origin are rejected.
  • OBS state, mute and screenshots use private same-origin HTTP, never public broadcast events. Only enumerated scene/mute actions are allowed.
  • Credentials are consumed by the existing local OBS configuration loader; their values must never enter docs, logs, Git or screenshots.
  • The old 8790 drawing service, public demo, Damas geometry, audio gain and VPS implementation are not modified.

Acceptance and rollback

Automated tests cover access denial, Host/Origin checks, fake OBS actions, pointer ownership, full-script startup with simulated pointers, private drawing replay and separation from OBS controls. They do not prove iPad palm handling, browser layout, real OBS scenes/audio or effective public network isolation.

  1. On iPad: draw with Pencil and rest palm; confirm no stray strokes or jumps. Try touch mode intentionally.
  2. Check Admin tabs, server-backed lists and camera permissions without losing the current drawing.
  3. With OBS idle: confirm actual scenes, the intended microphone, periodic still screenshots and transparent crystal output. Never start a stream as a test.
  4. Close menus, rotate iPad, hide the page and reconnect. Confirm errors, capture pause and drawing replay.
  5. Rollback: remove the opt-in flag and restart only the approved panel process. Existing Admin and data remain unchanged; no migration is needed.
